# victorzhangcodex · 追主线波段打法（cc v4）盘前计划

A 股波段交易的盘前计划与策略工作区。核心方法论为 **cc v4「追主线波段打法体系」**：市场分化时识别「资金持续集中流入的方向」，用核心股趋势 + 账户纪律做波段。

## 目录

```
盘前计划/    每日盘前计划（cc v4 六步流程 + 四张表）
strategies/  策略脚本（cc_scan.py / cc_moneyflow.py / cc_ignition_scan.py，见下方说明）
docs/        方法论文档
```

## cc v4 方法论速览

- **主线评分（0–100，四维替代涨停家数）**：板块资金连续流入(20) + 成交额放大(20) + 核心股趋势(20) + 相对指数强度(15) + 内部宽度(10) + 催化质量(10) + 市场背景(5)。≥75 主线成立，60–74 观察，<60 不交易。
- **个股四角色**：龙头 / 中军 / 卡位 / 跟风。卖出按「先跟风 → 中军 → 龙头」。
- **三段论**：抓①启动期、不追涨停；量在价先；资金双源交叉验证。
- **买点模式**：左侧启动(5–8%) / 回踩确认(8–12%) / 右侧接力(<8%)。
- **仓位纪律**：单股 ≤25%，单主题 ≤55%，黄色市场留 25–35% 现金。
- **数据分工**：iFinD 主力/盘中 · Tushare 盘后批量 · 爱分享研报逻辑验证 · 台账组合约束。

完整框架见 `docs/`（源文档：`追主线波段打法体系（cc v4）2026-06-19`）。

## ⚠️ 关于数据源（Claude Code on the web 环境）

本仓库在 Claude Code 云端环境中运行时，**外部行情接口被网络策略拦截**：
`api.tushare.pro`、`push2.eastmoney.com`、`hq.sinajs.cn` 等均返回 403，**无法实时拉取行情/资金数据**。

因此在该环境生成盘前计划时：

- ✅ 可用：联网新闻搜索（周五收盘复盘、周末消息面、板块级资金、龙头名单、催化）。
- ❌ 不可用：Tushare/东财/新浪的个股级双源资金流、MA/换手/量比等技术字段。

**要得到精确评分与触发价**：在本地跑 `cc_scan.py` / `cc_moneyflow.py`，或从 iFinD/choice/Tushare 导出后，把结果上传到会话，再回填到当日计划。
